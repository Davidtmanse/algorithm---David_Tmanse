### 双指针
### Java写法
```
import java.util.*;

public class Main{
    private static int N = 100010;
    private static int[] q = new int[N];
    private static int[] s = new int[N];
    
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        
        int n = sc.nextInt();
        for (int i = 0; i < n; i ++) q[i] = sc.nextInt();
        
        int cnt = 0;
        for (int i = 0, j = 0; i < n; i ++){
            s[q[i]] ++;
            while (j < i && s[q[i]] > 1) s[q[j ++]] --;
            cnt = Math.max(cnt, i - j + 1);
        }
        
        System.out.println(cnt);
    }
}
```

#### 我以为我理解双指针了，然而并没有（这回真理解了）
```

#include <iostream>

using namespace std;

const int N = 100010;
int n;
int a[N] , s[N];

int main()
{
    cin >> n;
    for (int i = 0 ; i < n ; i ++) cin >> a[i];
    
    int res = 0;
    for (int i = 0 , j = 0; i < n ; i ++)
    {
        s[a[i]] ++;
        while (j < i && s[a[i]] > 1) s[a[j ++]] --;
        res = max(res , i - j + 1);
    }
    
    cout << res << endl;
    return 0;
}

```

***
输入
纯文本
`n = 5`
`q = [1, 2, 2, 3, 5]`
> 下标: 0  1  2  3  4


`s[x]` 记录 `x` 出现了几次

`res 初始 = 0`

逐轮推演（重点看 i=2 那轮）
i = 0（右指针指向 1）

`s[1] = 1`

`j = 0`

不进 `while`

`res = max(0, 0-0+1) = 1`

`i = 1`（右指针指向 2）

`s[2] = 1`

`j = 0`

不进 `while`

`res = max(1, 1-0+1) = 2` ✅（窗口 [1,2]）

⭐ i = 2（右指针指向第二个 2）——关键来了

此时数组：

纯文本
> 下标: 0  1  2
值:   1  2 [2]
`j = 0`

执行：


`s[q[2]]++;`   // `s[2]` 原来是`1`，现在变成 `2`

`s[q[i]] > 1` → 进 `while`

`while` 第一次：

`s[q[j++]]--;`

等价于：

`s[q[0]]--;`   // s[1] 从1变0
`j = 1;`       // j 变成1

检查：`j(1)` < `i(2)` 且 `s[2]==2>1` → 继续 `while`

`while` 第二次：

`s[q[j++]]--;`

等价于：

`s[q[1]]--;`   // `s[2]` 从`2`变`1`
`j = 2;`      // `j` 变成`2`

现在 `s[2] == 1`，`j(2)` < `i(2)` 不成立，跳出 `while`

✅ 此时 `j = 2`

算长度：

`res = max(res, i - j + 1);` // 2 - 2 + 1 = 1

窗口现在是 `[q[2]]` 也就是 `[2]`，长度 `1`

res 还是之前的 2

👉 你以为长度是 4，是因为你算 `i-j+1` 时 j 还以为是 0 或 1，其实 `while` 结束 j 已经跑到 2 了

`i = 3`（值 3）

`s[3] = 1`

`j = 2`

不重复，不进 `while`

`res = max(2, 3-2+1) = 2` → 窗口是 [2,3]

`i = 4`（值 5）

`s[5] = 1`

`j = 2`

不重复

`res = max(2, 4-2+1) = 3` ✅

最终答案 = 3

最长无重复子数组是：
> 
纯文本
下标 2 3 4
值   2 3 5


`s[q[j++]]--`
等价于：
```
while (j < i && s[q[i]] > 1) {
    int val = q[j];   // 当前左端点的值
    s[val]--;         // 计数减掉
    j++;              // 左指针右移
}
```
